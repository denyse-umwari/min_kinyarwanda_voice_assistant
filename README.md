# Mini-Kinyarwanda Voice Assistant

A humanoid robot voice interaction system that understands and responds to Kinyarwanda speech.

## Features

- Speech-to-text using Whisper
- Kinyarwanda question understanding
- Text-to-speech responses

## Setup

1. Install requirements: `pip install -r requirements.txt`
2. Run the assistant: `python assistant.py`

## Usage

1. Speak your question in Kinyarwanda when prompted
2. The system will respond with the appropriate answer
3. Press Ctrl+C to exit

## Q&A Pairs

- "Rwanda Coding Academy iherereye he?" → "Iherereye mu Karere ka Nyabihu..."
- "Umurwa mukuru w'u Rwanda ni uwuhe?" → "Ni Kigali."
